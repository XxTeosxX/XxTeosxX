### 🚀 Featured project — MCP Agent Gateway

A secure, production-grade gateway that gives AI agents **audited, least-privilege access**
to Google Drive and Slack over the **Model Context Protocol** — without ever leaking the
user's identity token to a third party (**Confused Deputy** prevention, proven by a
regression test).

`FastAPI` · `MCP / Streamable HTTP` · `OAuth 2.1 (RFC 9728 / 7591)` · `Redis` · `OpenTelemetry`
Built with an AI-native SDLC (Claude Code + MCP, spec-driven), with CI, security scanning, and a full test suite.
